# Security and privacy

This repository contains a generic skill, not a place to store personal financial records.

## Never publish

- real balances, transactions, holdings, statements, tax records, payroll records, or insurance documents;
- screenshots containing names, account identifiers, addresses, QR codes, or policy numbers;
- passwords, verification codes, access tokens, API keys, private keys, or recovery information.

Use synthetic or fully anonymized examples in issues and pull requests. If a secret is exposed, revoke or rotate it at the provider first, then remove it from the repository history and report the incident privately through GitHub's security reporting features when available.

The skill defaults to read-only analysis. Any connection to an account or any external action must be separately authorized at the time of the action, with the narrowest practical permission scope.
